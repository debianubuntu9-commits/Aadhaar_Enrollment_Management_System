# Aadhaar Enrollment Management System

## 1. Project Overview

The **Aadhaar Enrollment Management System** is a full-stack web application developed to manage citizen Aadhaar enrollment information.

The project consists of three main components:

- **Frontend** – Collects input from the user and displays stored data.
- **Backend** – Handles API requests, validation, and communication with the database.
- **Database** – Stores citizen, enrollment center, application, and biometric information.
